# 90 Days AI × Web Development

Ai × フルスタックWeb開発を90日間学習する記録です。

## Goal

90日間でWeb開発の基礎を身に着け、AIを組み込んだWebサービスを開発できるようになる。

## Day 1

-VS Codeの環境構築
-HTMLの基礎
-CSSの基礎
-Git / GitHubの導入 -初めてのcommit / push

## Day 2

-The Odin ProjectでWeb開発の基礎を学習
-Git / GitHub / HTMLの基礎知識を硬めた

## Day 3

-The Odin ProjectでHTML / CSSの基礎を学習
-CSSのカスケード/詳細度/継承
-DevToolsの使い方
-box-sizing など

## Day 4

-flex-grow / shrink / basis
-justify-content / align-items
-flex-wrap / align-content
-auto margins / order など

## Day 5

-The Odin Projectに取り組んだ
-Landing Page完成！
-Flexboxで各セクションを実装してGitHubにpushした。
